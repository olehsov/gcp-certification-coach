# Reading the learner's answer

Apply these rules before scoring any answer (quiz, pre-test, warm-up, mock). They are the same in every language; recognize the equivalent phrases in the learner's language.

## Confidence scale

**1 guess or unsure · 2 fairly confident · 3 sure.** Show these words in the question prompt.

## Rules, in order

1. **Unclear or cut-off message** (no option, a fragment, two contradictory answers): ask again. Never score it.
2. **Explicit confidence wins.** A number (1, 2, 3) or a scale word ("guess", "fairly confident", "sure") is used as given, even with a hedge next to it ("probably B, confidence 2" is 2).
3. **Hedge with no explicit confidence → 1.** Examples: "probably B", "I think the first one", "maybe C", "not sure, A?", "A or B, leaning A", "no idea, D". The hedged option is the answer.
4. **Unclear wording with no explicit confidence → ask.** For example "pretty sure B", "fairly certain it's A", "B, I'd say": ask "Confidence 1, 2 or 3?" before scoring. Do not assume.
5. **No clear letter.** "The third option", "the Bigtable one", "the last two": say which letter(s) you read ("You chose C (Bigtable), right?") and score only after the learner confirms. Ask the confidence in the same message if it is also missing.
6. **Multi-select:** the answer must name exactly the requested number of options; otherwise ask.

## Effects

- Confidence 1 never creates a misconception, whatever the answer.
- Record the confidence actually used in the log entry, and tell the learner when it came from a hedge: "Read as confidence 1 (unsure)."
